# Challenge interpretation

**NASA Space Apps Challenge 2026 — Be An Earth System Trend Detective!**  
Difficulty: Advanced · Subjects: Earth Science, Software  
Official challenge: https://www.spaceappschallenge.org/2026/challenges/earth-system-trend-detective/

## The four questions

1. **What is changing?** Identify a clearly defined Earth-science variable and its source.
2. **Where is it changing?** Specify the geographic footprint or measurement location and its resolution.
3. **How much is it changing?** Estimate and communicate the direction, rate, and uncertainty of the change.
4. **Is the trend significant?** Apply a documented statistical method and communicate the result without overclaiming.

## NASA's stated objectives

- Select variables observed by NASA missions or generated by NASA Earth-system models.
- Acquire measurements for an area of scientific interest.
- Produce and visualize a sufficiently long time series.
- Estimate the rate of change and evaluate statistical significance (for example, with a t-test, Mann-Kendall, or confidence intervals).

The challenge's official description recommends exploring local differences, providing approachable variable explanations, and using daily or monthly data to simplify analysis. AI-assisted variable discovery is optional, not a scientific prerequisite.

## Resource catalog and optional ideas

The [curated NASA challenge resource catalog](NASA-CHALLENGE-RESOURCES.md) preserves the tools and scientific/partner references provided in the official Resources tab, with distinct levels of applicability to TELLURIS. Their listing does not imply NASA endorsement, automatically permit third-party data reuse, or establish that each tool has been integrated.

The challenge also suggests guided question-based discovery, demonstrations, clear variable definitions, and optional AI-assisted discovery. It explicitly allows a **basic linear trend** as a valid starting point. None of these suggestions substitutes for the required data-backed significance analysis.

## How TELLURIS intends to address the brief

| Objective | Intended capability | Proof needed |
| --- | --- | --- |
| Select variables | Source-aware variable catalog | Variable metadata, meaning, units, provider |
| Locate trends | Map selection with precise spatial labeling | Coordinates or a documented aggregation footprint |
| Visualize change | Historical chart with missing-data treatment | Traceable input observations |
| Quantify trend | Estimated slope and units per decade | Reproducible calculation |
| Test significance | Named test, p-value/CI and limitations | Independent verification and sample counts |
| Communicate | Plain-language evidence report | Same values as the underlying analysis |

**Current verification state:** These are requirements and acceptance criteria. No completed integration, computed results, or deployment is asserted here.

## Scientific boundary

Statistical significance does not prove causality. Absence of statistical significance does not establish absence of change. A point-based POWER estimate must not be described as a measured province-wide mean unless a legitimate regional aggregation is implemented and documented.
