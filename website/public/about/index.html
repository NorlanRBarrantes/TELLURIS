TELLURIS / Sobre Project Uriel

SOBRE EL EQUIPO · PROJECT URIEL

La curiosidad nos impulsa.
La evidencia nos guía.

Somos Project Uriel, una iniciativa interdisciplinaria independiente de Costa Rica. Construimos TELLURIS para convertir preguntas del sistema terrestre en investigaciones comprensibles, verificables y útiles.

01El equipo

Personas y tecnología detrás de TELLURIS

Nuestro trabajo reúne capacidades en software, integraciones, automatización y áreas técnicas de electrónica y electricidad. Colaboramos para transformar datos complejos en herramientas accesibles, sin presentarnos como una misión o entidad oficial de NASA.

01 / SOFTWARE E INTEGRACIONES

SOFTWARE E INTEGRACIONES

Desarrollo web, APIs, procesamiento de datos, interoperabilidad y aplicaciones que conectan servicios con experiencias reales.

02 / AUTOMATIZACIÓN Y SISTEMAS

AUTOMATIZACIÓN Y SISTEMAS

Diseño de procesos reproducibles, validaciones técnicas, trazabilidad, despliegue y monitoreo.

03 / ELECTRÓNICA Y ELECTRICIDAD

ELECTRÓNICA Y ELECTRICIDAD

Conocimientos técnicos aplicados a sistemas físicos, electrónica y trabajo en el área eléctrica.

04 / COMUNICACIÓN CIENTÍFICA

COMUNICACIÓN CIENTÍFICA

Visualización, documentación y explicación de resultados, fuentes, incertidumbre y limitaciones de manera comprensible.

02Nuestros principios

Cómo trabajamos

El proyecto parte de preguntas claras, emplea datos públicos NASA cuando están disponibles y separa código, fuentes y hallazgos. Las pruebas automatizadas no sustituyen la validación científica ni la evaluación humana.

PROJECT URIEL · 2026

Nuestra participación

TELLURIS fue desarrollado para NASA Space Apps Challenge 2026, desafío «Be An Earth System Trend Detective!». Project Uriel es un equipo participante independiente; no constituye una división de NASA.

TRACEABILITY / GITHUB

Repositorio y documentación técnica

El código y la documentación registran metodologías, decisiones y pruebas; no se presentan como validaciones independientes de cada conclusión climática.
